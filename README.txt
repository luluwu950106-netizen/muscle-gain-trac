增肌追蹤器 PWA

這個資料夾已包含可安裝的 PWA 檔案：
- index.html
- manifest.webmanifest
- sw.js
- icon-180.png
- icon-512.png

重要：iPhone 不能把 ZIP/本機 HTML 直接當成完整 PWA 安裝。
請先把這些檔案部署到 HTTPS 網址（例如 GitHub Pages、Cloudflare Pages、Netlify 等）。
部署後：
1. 用 Safari 開啟該網址
2. 點「分享」
3. 選「加入主畫面」
4. 名稱保留「增肌追蹤器」→ 加入

之後會像 App 一樣從主畫面開啟，並使用瀏覽器儲存紀錄。
